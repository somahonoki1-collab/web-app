# 成長対戦の初版（sqrt-v1）

## 使い方

1. 下部の「成長対戦」を開き、グループを作成する。
2. 招待コードを仲間に共有する。仲間はログインし、「招待コードで参加」から参加する。複数グループに所属できる。
3. 参加者がそろったら管理者が対戦名、複数の種目、種目ごとの期間（1〜12カ月）を選んで開始する。
4. 種目名が仲間の登録名と一致すれば自動で対応する。異なる名前の場合は、仲間が対戦画面で自分の対応種目を選ぶ。同じ動作・器具・重量の数え方で比較する。
5. いつもどおり記録する。ホームでの複数セット保存、またはメニューのトレーニングの完了により、対象成績と暫定順位が更新される。
6. 期限後にグループか対戦画面を開くと結果を発表し、順位と成長ポイント推移グラフを保存・表示する。グラフの点や記録一覧から、自分のカレンダーの記録日へ移動できる。

参加者と採点ルールは開始時に固定する。開始後にグループへ参加した人は、次の対戦から参加する。

## 成績の選び方

ユーザーが選んだ**推定1RMを初期設定**にしている。回数が伸びた場合も成長として扱う。

```text
推定1RM = 重量 × (1 + 回数 / 40)
スクワットのみ、分母は33.3
1回のセットは実重量
```

- 既存アプリの推定式に合わせ、1〜12回のセットを対象とする。13回以上のセットも通常の記録には保存されるが、成長対戦の対象には含めない。
- 1回のトレーニングで最大の推定1RMとなるセットが代表成績。同値なら実重量の高いセット、それも同値なら先に保存されたセットを使う。
- 名前の違う種目を対応させても、管理者が選んだ対戦種目の推定式を全員に適用する。
- 「同じ回数で挙げた重量」も対戦作成時に選択できる。その場合、指定回数と一致するセットの最大重量を使う。
- 推定値は普段のセットから求めた筋力の目安であり、実測の最大筋力ではない。通常の記録と同じように器具・動作・可動域などの条件をそろえる。

実重量の増減も表示する。これは開始・終了の代表セットの重量差であり、推定1RMの対戦では異なる回数のセットを比較することがある。

## ポイント

```text
B = 開始成績
E = 終了成績
R = 種目の配点基準（開始時に固定、参加者共通）
補正倍率 = min(2.0, max(0.5, √(B / R)))
ポイント = 100 × (E − B) / R × 補正倍率
```

Rの初期値はスクワット100kg、その他60kg。平均筋力・限界重量・目標を表す値ではなく、点数の尺度。対戦開始前に管理者が0.1〜1000kgの範囲で設定できる。

例えばR=60kgで成績40→60kgなら27.22pt、80→100kgなら38.49pt。同じ成績増加に対して、開始水準が高い人へ緩やかな補正を付ける。

- ポイントは小数第2位に丸めて順位を付ける。同点は同順位（例：1位・1位・3位）。
- 2回以上の対象トレーニングがある人が順位対象。開始のみ・記録なしは0点扱いにせず、順位対象外と表示する。
- 成績が減った場合はマイナスポイントになる。
- 順位は種目ごと。異なる種目の生ポイントを合計した総合順位は初版には含めない。
- グラフはB・R・補正倍率を固定し、各回の成績をEとして同じ式を使う。最初の点は0ptとなる。

指数0.5と倍率制限はアプリ独自の競争ルール。論文で公平さが検証された係数ではない。体重・性別・年齢・経験・再開による補正は含めていない。調査資料は `research/GROWTH_SCORE_RESEARCH.md`。

## 期間と記録修正

- 開始は設定完了時点、終了はその時点から指定した暦の月数後。月末に対応日がない場合は、その月の末日にする。時刻は日本時間。
- 期間は「開始時刻以上、終了時刻未満」。種目ごとに異なる月数を指定できるが、同じ種目の参加者は共通の開始時刻・締切で競う。
- 設定前に保存されていた記録は開始成績にしない。ホームのまとめ保存は1回、メニューのトレーニングも対象種目ごとに1回として扱う。
- メニューのトレーニングは開始・完了の両方が期間内のものを対象とする。終了後に完了したメニューのトレーニングや、設定前から実施中だったメニューのトレーニングは対象外。
- 設定後の最初の対象トレーニングが開始成績、期間内の最後が終了成績。期間中の最高成績を終了成績として選び直す方式ではない。
- 期間中の修正・削除は暫定成績を再集計する。最初の対象トレーニングを削除・対象外に変更すると、開始成績も変わる。
- 締切後の修正・削除では結果を変えない。成績の写しを保存しているため、元の記録を削除しても結果・グラフは残る。カレンダーには、その時点で残っている記録が表示される。
- 結果発表は締切後のグループ・対戦画面の閲覧時に行う。バックグラウンドでの通知は初版には含めない。
